# Experimente a paginação

Esta frase realçada é um destino de navegação.

Use o índice para rolar até o destaque. Os quatro botões abaixo do container levam ao primeiro, anterior, próximo ou último arquivo.

## Continue no modo foco

Abra o modo foco e mude a página do container. A janela permanece aberta e inicia o arquivo selecionado na primeira seção. Use Ctrl+K para encontrar a Lição 2 ou a Lição 3 diretamente.

> Versão: 0.0.17
