# Rose Light

Soft rose light theme for modern documentation

| Field | Value |
| --- | --- |
| Id | `rose-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/rose-light.json`](../templates/rose-light.json) |
| Light/dark pairing | Paired light/dark group: `rose-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "rose-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=rose-light`.
