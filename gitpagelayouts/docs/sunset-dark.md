# Sunset Dark

Warm dark theme with orange + pink accents (sunset vibe)

| Field | Value |
| --- | --- |
| Id | `sunset-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/sunset-dark.json`](../templates/sunset-dark.json) |
| Light/dark pairing | Paired light/dark group: `sunset-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "sunset-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=sunset-dark`.
