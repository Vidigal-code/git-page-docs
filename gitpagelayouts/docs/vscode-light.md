# VSCode Light

Visual Studio Code Light+ theme with clean editor tones

| Field | Value |
| --- | --- |
| Id | `vscode-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/vscode-light.json`](../templates/vscode-light.json) |
| Light/dark pairing | Paired light/dark group: `vscode-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "vscode-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=vscode-light`.
