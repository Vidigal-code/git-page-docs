# Mono Pro Light

Minimal light theme with lime accent and clean surfaces

| Field | Value |
| --- | --- |
| Id | `mono-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/mono-light.json`](../templates/mono-light.json) |
| Light/dark pairing | Paired light/dark group: `mono-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "mono-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=mono-light`.
