# Plum

Dark plum canvas with violet and rose accents

| Field | Value |
| --- | --- |
| Id | `plum-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/plum-dark.json`](../templates/plum-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "plum-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=plum-dark`.
