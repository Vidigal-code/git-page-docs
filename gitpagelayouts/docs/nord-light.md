# Nord Light

Calm Nord-inspired light theme (clean, readable, modern)

| Field | Value |
| --- | --- |
| Id | `nord-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/nord-light.json`](../templates/nord-light.json) |
| Light/dark pairing | Paired light/dark group: `nord-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "nord-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=nord-light`.
