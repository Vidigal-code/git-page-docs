# Cyberpunk Light

Futuristic light theme with bright pink and cyan accents

| Field | Value |
| --- | --- |
| Id | `cyberpunk-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/cyberpunk-light.json`](../templates/cyberpunk-light.json) |
| Light/dark pairing | Paired light/dark group: `cyberpunk-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "cyberpunk-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=cyberpunk-light`.
