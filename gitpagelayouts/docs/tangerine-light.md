# Tangerine

Bright tangerine orange on a light canvas

| Field | Value |
| --- | --- |
| Id | `tangerine-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/tangerine-light.json`](../templates/tangerine-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "tangerine-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=tangerine-light`.
