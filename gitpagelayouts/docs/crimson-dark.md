# Crimson

Dark canvas with bold crimson accents

| Field | Value |
| --- | --- |
| Id | `crimson-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/crimson-dark.json`](../templates/crimson-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "crimson-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=crimson-dark`.
