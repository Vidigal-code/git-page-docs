# Blush

Soft blush pinks on an airy light canvas

| Field | Value |
| --- | --- |

| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/blush-light.json`](../templates/blush-light.json) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "blush-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=blush-light`.
