# Moss

Dark forest canvas with mossy green accents

| Field | Value |
| --- | --- |
| Id | `moss-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/moss-dark.json`](../templates/moss-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "moss-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=moss-dark`.
