# Mint

Fresh mint greens on a clean light canvas

| Field | Value |
| --- | --- |
| Id | `mint-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/mint-light.json`](../templates/mint-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "mint-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=mint-light`.
