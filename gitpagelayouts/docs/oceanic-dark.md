# Oceanic Dark

Deep ocean dark UI with cyan and blue accents

| Field | Value |
| --- | --- |
| Id | `oceanic-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/oceanic-dark.json`](../templates/oceanic-dark.json) |
| Light/dark pairing | Paired light/dark group: `oceanic-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "oceanic-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=oceanic-dark`.
