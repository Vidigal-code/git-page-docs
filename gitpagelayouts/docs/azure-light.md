# Azure

Open sky-blue accents on a bright canvas

| Field | Value |
| --- | --- |
| Id | `azure-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/azure-light.json`](../templates/azure-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "azure-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=azure-light`.
