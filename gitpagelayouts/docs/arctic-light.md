# Arctic

Icy whites with cool glacier-blue accents

| Field | Value |
| --- | --- |
| Id | `arctic-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/arctic-light.json`](../templates/arctic-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "arctic-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=arctic-light`.
