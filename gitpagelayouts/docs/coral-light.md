# Coral

Warm coral and peach on a soft light canvas

| Field | Value |
| --- | --- |
| Id | `coral-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/coral-light.json`](../templates/coral-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "coral-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=coral-light`.
