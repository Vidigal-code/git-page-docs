# Slate Light

Professional slate light theme with neutral tones

| Field | Value |
| --- | --- |
| Id | `slate-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/slate-light.json`](../templates/slate-light.json) |
| Light/dark pairing | Paired light/dark group: `slate-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "slate-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=slate-light`.
