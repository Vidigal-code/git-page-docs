Dark emerald style with refined green contrast

| Field | Value |
| --- | --- |
| Id | `emerald-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/emerald-dark.json`](../templates/emerald-dark.json) |
| Light/dark pairing | Paired light/dark group: `emerald-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "emerald-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=emerald-dark`.
