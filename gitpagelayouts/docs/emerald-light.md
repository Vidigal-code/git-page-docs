# Emerald Light

Elegant emerald light style for readable docs

| Field | Value |
| --- | --- |
| Id | `emerald-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/emerald-light.json`](../templates/emerald-light.json) |
| Light/dark pairing | Paired light/dark group: `emerald-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "emerald-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=emerald-light`.
