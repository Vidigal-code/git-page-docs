# Matrix Dark

Dark theme with neon green accents inspired by The Matrix

| Field | Value |
| --- | --- |
| Id | `matrix-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/matrix-dark.json`](../templates/matrix-dark.json) |
| Light/dark pairing | Paired light/dark group: `matrix-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "matrix-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=matrix-dark`.
