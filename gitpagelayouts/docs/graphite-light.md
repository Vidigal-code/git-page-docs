# Graphite Light

Minimal graphite light interface with calm contrast

| Field | Value |
| --- | --- |
| Id | `graphite-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/graphite-light.json`](../templates/graphite-light.json) |
| Light/dark pairing | Paired light/dark group: `graphite-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "graphite-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=graphite-light`.
