# Forest Dark

Moody forest dark theme with green accents

| Field | Value |
| --- | --- |
| Id | `forest-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/forest-dark.json`](../templates/forest-dark.json) |
| Light/dark pairing | Paired light/dark group: `forest-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "forest-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=forest-dark`.
