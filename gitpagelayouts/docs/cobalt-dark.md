# Cobalt

Deep blue canvas with vivid cobalt highlights

| Field | Value |
| --- | --- |
| Id | `cobalt-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/cobalt-dark.json`](../templates/cobalt-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "cobalt-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=cobalt-dark`.
