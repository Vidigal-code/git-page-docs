# Violet Light

Violet light palette with smooth, modern highlights

| Field | Value |
| --- | --- |
| Id | `violet-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/violet-light.json`](../templates/violet-light.json) |
| Light/dark pairing | Paired light/dark group: `violet-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "violet-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=violet-light`.
