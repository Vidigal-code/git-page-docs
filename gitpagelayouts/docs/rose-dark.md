# Rose Dark

Elegant dark rose palette with pink highlights

| Field | Value |
| --- | --- |
| Id | `rose-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/rose-dark.json`](../templates/rose-dark.json) |
| Light/dark pairing | Paired light/dark group: `rose-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "rose-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=rose-dark`.
