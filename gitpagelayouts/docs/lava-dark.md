# Lava Dark

Bold dark magma palette with hot orange accents

| Field | Value |
| --- | --- |
| Id | `lava-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/lava-dark.json`](../templates/lava-dark.json) |
| Light/dark pairing | Paired light/dark group: `lava-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "lava-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=lava-dark`.
