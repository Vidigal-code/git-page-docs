# Amber Light

Warm amber light interface with soft gold tones

| Field | Value |
| --- | --- |
| Id | `amber-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/amber-light.json`](../templates/amber-light.json) |
| Light/dark pairing | Paired light/dark group: `amber-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "amber-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=amber-light`.
