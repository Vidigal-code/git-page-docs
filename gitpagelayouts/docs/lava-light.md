# Lava Light

Warm light lava palette with energetic contrast

| Field | Value |
| --- | --- |
| Id | `lava-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/lava-light.json`](../templates/lava-light.json) |
| Light/dark pairing | Paired light/dark group: `lava-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "lava-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=lava-light`.
