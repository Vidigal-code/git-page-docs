Night skyline dark blue palette with neon cyan

| Field | Value |
| --- | --- |
| Id | `skyline-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "skyline-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=skyline-dark`.
