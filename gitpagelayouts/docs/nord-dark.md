# Nord Dark

Calm Nord-inspired dark theme (icy blues, low contrast glare)

| Field | Value |
| --- | --- |
| Id | `nord-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/nord-dark.json`](../templates/nord-dark.json) |
| Light/dark pairing | Paired light/dark group: `nord-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "nord-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=nord-dark`.
