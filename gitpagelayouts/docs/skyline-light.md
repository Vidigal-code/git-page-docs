# Skyline Light

Airy skyline light palette with cool blue accents

| Field | Value |
| --- | --- |
| Id | `skyline-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/skyline-light.json`](../templates/skyline-light.json) |
| Light/dark pairing | Paired light/dark group: `skyline-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "skyline-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=skyline-light`.
