Rich emerald greens on a dark canvas

| Field | Value |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "verdant-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=verdant-dark`.
