# Carbon

Near-black graphite with crisp white accents

| Field | Value |
| --- | --- |
| Id | `carbon-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/carbon-dark.json`](../templates/carbon-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "carbon-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=carbon-dark`.
