# Sunset Light

Warm light theme with orange + rose accents (soft, modern UI)

| Field | Value |
| --- | --- |
| Id | `sunset-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/sunset-light.json`](../templates/sunset-light.json) |
| Light/dark pairing | Paired light/dark group: `sunset-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "sunset-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=sunset-light`.
