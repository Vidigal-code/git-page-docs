# Aurora Dark

Modern dark theme with purple + cyan accents and glassy cards

| Field | Value |
| --- | --- |
| Id | `aurora-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/aurora-dark.json`](../templates/aurora-dark.json) |
| Light/dark pairing | Paired light/dark group: `aurora-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "aurora-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=aurora-dark`.
