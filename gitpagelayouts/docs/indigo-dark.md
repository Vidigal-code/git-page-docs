# Indigo

Deep indigo canvas with violet highlights

| Field | Value |
| --- | --- |
| Id | `indigo-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/indigo-dark.json`](../templates/indigo-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "indigo-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=indigo-dark`.
