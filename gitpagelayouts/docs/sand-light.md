# Sand

Warm desert sand and beige on light canvas

| Field | Value |
| --- | --- |
| Id | `sand-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/sand-light.json`](../templates/sand-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "sand-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=sand-light`.
