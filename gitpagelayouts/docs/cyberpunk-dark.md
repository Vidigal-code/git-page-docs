# Cyberpunk Dark

Futuristic dark theme with neon pink and cyan accents

| Field | Value |
| --- | --- |
| Id | `cyberpunk-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/cyberpunk-dark.json`](../templates/cyberpunk-dark.json) |
| Light/dark pairing | Paired light/dark group: `cyberpunk-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "cyberpunk-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=cyberpunk-dark`.
