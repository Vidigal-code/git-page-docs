# Violet Dark

Modern violet dark gradient with vivid contrast

| Field | Value |
| --- | --- |
| Id | `violet-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/violet-dark.json`](../templates/violet-dark.json) |
| Light/dark pairing | Paired light/dark group: `violet-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "violet-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=violet-dark`.
