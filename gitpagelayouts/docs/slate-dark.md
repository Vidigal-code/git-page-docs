# Slate Dark

Professional slate dark theme for technical docs

| Field | Value |
| --- | --- |
| Id | `slate-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/slate-dark.json`](../templates/slate-dark.json) |
| Light/dark pairing | Paired light/dark group: `slate-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "slate-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=slate-dark`.
