# Aurora Light

Modern light theme with purple + teal accents and soft shadows

| Field | Value |
| --- | --- |
| Id | `aurora-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/aurora-light.json`](../templates/aurora-light.json) |
| Light/dark pairing | Paired light/dark group: `aurora-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "aurora-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=aurora-light`.
