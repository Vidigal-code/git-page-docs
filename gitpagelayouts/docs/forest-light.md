# Forest Light

Fresh forest light theme with natural greens

| Field | Value |
| --- | --- |
| Id | `forest-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/forest-light.json`](../templates/forest-light.json) |
| Light/dark pairing | Paired light/dark group: `forest-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "forest-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=forest-light`.
