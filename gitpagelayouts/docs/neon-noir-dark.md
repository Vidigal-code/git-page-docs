# Neon Noir

Black canvas with magenta and cyan neon

| Field | Value |
| --- | --- |
| Id | `neon-noir-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/neon-noir-dark.json`](../templates/neon-noir-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "neon-noir-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=neon-noir-dark`.
