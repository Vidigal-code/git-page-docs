# Graphite Dark

Premium graphite dark interface with blue glow

| Field | Value |
| --- | --- |
| Id | `graphite-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/graphite-dark.json`](../templates/graphite-dark.json) |
| Light/dark pairing | Paired light/dark group: `graphite-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "graphite-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=graphite-dark`.
