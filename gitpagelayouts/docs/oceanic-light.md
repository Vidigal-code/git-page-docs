# Oceanic Light

Clean ocean light UI with soft aqua accents

| Field | Value |
| --- | --- |
| Id | `oceanic-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/oceanic-light.json`](../templates/oceanic-light.json) |
| Light/dark pairing | Paired light/dark group: `oceanic-1` |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "oceanic-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=oceanic-light`.
