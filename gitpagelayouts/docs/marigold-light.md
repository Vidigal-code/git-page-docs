# Marigold

Warm marigold amber on a bright canvas

| Field | Value |
| --- | --- |
| Id | `marigold-light` |
| Mode | `light` |
| Author | Kauan Vidigal |
| Template | [`templates/marigold-light.json`](../templates/marigold-light.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "marigold-light" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=marigold-light`.
