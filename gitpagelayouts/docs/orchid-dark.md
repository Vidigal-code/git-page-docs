# Orchid

Dark canvas with orchid purple and pink

| Field | Value |
| --- | --- |
| Id | `orchid-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/orchid-dark.json`](../templates/orchid-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "orchid-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=orchid-dark`.
