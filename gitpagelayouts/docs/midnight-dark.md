# Midnight

Deep navy canvas with electric-blue accents

| Field | Value |
| --- | --- |
| Id | `midnight-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |
| Template | [`templates/midnight-dark.json`](../templates/midnight-dark.json) |
| Light/dark pairing | Standalone (single mode) |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "midnight-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=midnight-dark`.
