# Amber Dark

Dark amber interface with rich golden accents

| Field | Value |
| --- | --- |
| Id | `amber-dark` |
| Mode | `dark` |
| Author | Kauan Vidigal |

## Usage

Set it as the default theme in `gitpagedocs/config.json`:

```json
{ "site": { "ThemeDefault": "amber-dark" } }
```

Or preview it on any Git Page Docs site via the URL parameter `?theme=amber-dark`.
